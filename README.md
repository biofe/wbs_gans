## WBS Coding School Project: Gans

Gans is a e-scooter company willing to expand to new cities. They want to focus on city trip tourists, who come in by plane. Therefore, incoming flights at the respective airports and the weather is interesting information that is pulled via API and the geographic position is scraped from Wikipedia.

### Tools

- Python:
  - Pandas
  - pymysql
  - requests
  - dotenv
  - BeautifulSoup
- [OpenWeather](https://openweathermap.org/)
- [AeroDataBox](https://rapidapi.com/aedbx-aedbx/api/aerodatabox)
- MySQL
- Docker / Podman
